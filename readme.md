# Library

A minimal, browser-based book tracker built for [The Odin Project](https://www.theodinproject.com/) JavaScript curriculum.

## Features

- **Add Books:** Add new entries with title, author, and pages read via a modal dialog.
- **Track Status:** Mark books as finished.
- **Remove Books:** Delete individual book cards from the library grid.
- **Dynamic Cards:** Generates unique IDs (`crypto.randomUUID()`) and randomized card background colors.

## Built With

- HTML5 (`<dialog>`)
- CSS3 (CSS Grid & Flexbox)
- Vanilla JavaScript (Object Constructors & Prototypes)
